# Короткий отчёт по тестам

Проверил обе части текущего спринта: регистрацию, логин/JWT и профиль клиента.

## Что есть сейчас

- На бэке 62 тестовые функции, которые при запуске разворачиваются в 159 тест-кейсов. Проверяются регистрация, логин, JWT, роли, `/auth/me`, профиль `/users/me`, health-check, миграции и создание сотрудников через CLI.
- На фронте пока 15 тестов, все в `profileValidation.test.ts`. Там валидация телефона, нормализация полей профиля и формирование payload для PATCH.
- CI есть в обеих репах. Бэк гоняет линтер, форматирование, тесты, миграции и сборку. Фронт — typecheck, линтер, форматирование, тесты и сборку.

## Что получилось запустить

- `scripts/manage.py check` прошёл: линтер, форматирование + 159 тестов от pytest.
- Фронт: `typecheck` проходит.
- Фронтовые unit-тесты: `15 passed`.
- `npm run check` останавливается на `prettier --check`: стиль не совпадает в 51 файле. Хорошо бы форматировать всегда.

## Что надо делать в следующих спринтах

1. На фронте решить, приводим ли всю репу к текущему Prettier. Если да — `npm run format`; После этого запускать `npm run check`.
2. Руками пройти основной сценарий: регистрация → логин → главная → профиль → изменить профиль → выйти.

## Что пока не покрыто тестами

- На фронте нет тестов на login/register, защищённые маршруты, обработку `401`, запросы к API и сохранение профиля.
- Нет E2E/smoke-проверки пользовательского сценария.
