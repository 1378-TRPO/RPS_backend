# QA-отчёт — гараж и услуги

Бэк зелёный: `scripts/manage.py check` прошёл полностью, выполнено 216 тест-кейсов.

По фронту появились новые unit-тесты для гаража и каталога услуг.

## Что добавили в спринте

- Гараж клиента: добавление и просмотр своих машин.
- Каталог активных услуг для клиента.
- Управление услугами для менеджера: создание, редактирование, удаление.
- На фронте: страницы `/garage`, `/services`, `/manager/services` и ограничение доступа к ним по роли.

## Что прогналось

- Бэк: `scripts/manage.py check` — `216 passed in 21.65s`.
- В проверку вошли линтер и форматирование: `All checks passed`, `55 files already formatted`.

Новые backend-сценарии покрыты тестами: доступ к гаражу только для клиента, изоляция машин разных клиентов, валидация машины, выдача только активных услуг, роли для менеджерских ручек, CRUD услуг и ограничения полей.

## Тесты на фронте

Есть 28 unit-проверок в четырёх файлах:

- `profileValidation.test.ts` — профиль;
- `vehicleValidation.test.ts` — валидация и payload машины;
- `serviceValidation.test.ts` — валидация цены, длительности и payload услуги;
- `serviceFormat.test.ts` — формат цены и длительности услуги.

## Что проверено руками

1. Клиент: логин → добавить машину → убедиться, что она видна только в своём гараже.
2. Менеджер: создать услугу, отредактировать и удалить её; проверить, что клиент видит только активные.

## Что пока не покрыто

- Нет E2E/smoke-теста базового сценария через playwright.
- На фронте нет компонентных/интеграционных тестов страниц, роутинга и запросов к API.
- Отчёт по покрытию пока не собирается автоматически.
